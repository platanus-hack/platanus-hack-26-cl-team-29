# docs

Registro de decisiones y hallazgos del proyecto.

- `decisiones/`: lo que elegimos y por qué.
- `hallazgos/`: lo que aprendimos en el camino.

## Formato

Un archivo por entrada, nombrado `AAAAMMDD-HHMM-titulo-corto.md`. La fecha en el nombre evita choques cuando varias personas escriben a la vez.

```markdown
# Título

Fecha: AAAA-MM-DD HH:MM
Autor:

## Contexto
Qué problema o pregunta había.

## Decisión / Hallazgo
Qué elegimos o qué encontramos, con datos concretos.

## Consecuencias
Qué cambia para el resto. Alternativas descartadas, si aplica.
```

Corto y concreto: un par de párrafos basta.
